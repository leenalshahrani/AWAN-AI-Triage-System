# AWAN Frontend

Frontend application for patient interaction and doctor dashboard.

---

## 🚀 Features

* Patient assessment form
* Doctor dashboard
* Risk visualization
* Responsive UI

---

## 🛠️ Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Axios

---

## ⚙️ Setup

```bash id="f1"
npm install
npm run dev
```

Runs on:
http://localhost:3000

---

## 🔄 Flow

1. Login using National ID
2. Submit symptoms
3. Receive AI classification
4. Display results

---

## 📡 API

Communicates with backend via REST APIs.

---

## 💡 Notes

* Backend must be running
* AI service required
